# Disha

**दिशा** — *direction*.

A phone-first guidance tool for a self-taught learner: it takes what you already
know, what you are aiming at, and what you actually have to work with — your
device, your time, your starting point — and returns a short, ordered learning
path built from free resources, with a small real project at every step, and an
honest map of the kinds of work that path leads to.

Built for the Bhopal Impact Lab, Problem Statement 2 — *"What should I learn next?"*
